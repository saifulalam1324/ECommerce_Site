
# 🛒 E-Commerce Website

A complete **E-Commerce Website** developed using Laravel with separate panels for **Customers, Vendors, and Administrators**.

The project includes a customer-facing shopping system where users can browse products and manage their purchases, a vendor panel for managing products and orders, and an admin panel for managing the overall platform, users, vendors, and products.

The main goal was to build a **multi-role e-commerce platform** with different functionalities and access levels for customers, vendors, and administrators.
